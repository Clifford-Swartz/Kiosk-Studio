# Issue Tracker

Issues for Kiosk Studio are tracked in [GitHub Issues](https://github.com/Clifford-Swartz/Kiosk-Studio/issues).

## For agents

When a skill creates, reads, or updates an issue:

- Use `gh issue` commands to interact with GitHub Issues
- Issues are created with `gh issue create --title "..." --body "..."`
- Labels are applied with `--label <label>`
- The five canonical triage labels are: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`

## For humans

Visit [Kiosk Studio Issues](https://github.com/Clifford-Swartz/Kiosk-Studio/issues) to view, create, and manage issues.
